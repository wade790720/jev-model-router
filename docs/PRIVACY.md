# 原型資料處理說明（上架前需依實際營運資料補成正式政策）

- 擴充功能只在 `chatgpt.com` 讀取目前「對話」或「工作」輸入框的文字草稿；不主動讀取聊天歷史、附件或圖片內容。草稿停頓約 950 毫秒後即可能送出判斷，**不必按下 ChatGPT 的傳送鍵**。
- 自備 key 模式：草稿文字直接由擴充功能傳至 TypeSafe AI。Key 存在使用者本機 Chrome／Edge 的擴充功能 `storage.local` 中，並非加密保險箱；共用電腦使用者應自行注意。
- 訂閱模式：草稿文字和訂閱啟用碼傳至部署者的 Cloudflare Worker。Worker 再將文字轉送 TypeSafe AI；程式碼不將草稿全文寫入 D1，也不刻意記錄在應用日誌。雲端平台及上游服務仍可能依其政策處理網路請求。
- D1 保存 Stripe subscription ID、啟用碼的 SHA-256 雜湊、訂閱狀態與時間；使用量表保存每分鐘／每天的請求數、token 數，以及雜湊後的結帳 IP 識別值，不保存明文啟用碼或明文 IP。
- 使用量窗口由排程刪除超過七天的紀錄。訂閱資料會保留至營運者依正式政策處理刪除請求；公開發佈前須明訂期限。
- Stripe Checkout 處理付款資料；本 Worker 不接觸卡號。Stripe 訂閱狀態透過簽章驗證的 webhook 更新。
- 擴充功能不出售草稿資料。對外發佈前需補上實際營運者、聯絡信箱、保存期限、刪除／查詢方式及各服務正式政策連結。
